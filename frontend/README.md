# Frontend – Proyecto Concurrente con IA

Interfaz web desarrollada con **React y Vite** para interactuar con el sistema multiagente de inteligencia artificial.

## Tecnologías

- React
- Vite
- JavaScript
- Recharts

## Instalación

Desde la carpeta `frontend`:

```powershell
npm install
```

## Ejecución en desarrollo

```powershell
npm run dev
```

La aplicación estará disponible habitualmente en:

http://localhost:5173

## Compilación para producción

```powershell
npm run build
```

## Backend

El frontend consume la API desarrollada con FastAPI. Para utilizar todas las funcionalidades, el backend debe estar iniciado previamente.
